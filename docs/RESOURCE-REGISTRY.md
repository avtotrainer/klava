## სინქრონიზაციის წესი

- ტექნიკური დოკუმენტი პირველად განახლდეს GitHub-ში; სხვაგან იდოს ბმული ან კონტროლირებადი ასლი.
- Drive-ის ფაილები არ გადმოიწეროს/გადაიტანოს/წაიშალოს ავტომატურად წინასწარი ნებართვის გარეშე.
- Slack-ში გამოიყენე მხოლოდ მნიშვნელოვანი GitHub CI/PR/Release შეტყობინებები; მიმდინარე ინტეგრაციები ჯერ არ არის გააქტიურებული.
- ChatGPT-ის ატვირთული Project Knowledge **არ ჩაითვალოს** GitHub/Drive-ის ცოცხალ სინქრონიზებულ ასლად.
- ავტომატიზაცია დანერგე ეტაპობრივად: CI → შეტყობინებები → Drive inventory → ცოდნის მოძველების კონტროლი.

## Known limitations

Registry ამ ეტაპზე ხელით განახლებადია. Slack Workspace-ის და მისი ავტომატიზაციების ხელმისაწვდომობა ჯერ დასადასტურებელია. GitHub Actions ამ ეტაპზე მხოლოდ კოდის შემოწმებას ასრულებს.
