# `Trainer` — სასწავლო სესიის მმართველი

**ფაილი:** `trainer.py`  
**კლასი:** `Trainer`  
**მდგომარეობა:** მიმდინარე კოდის აღწერა, 2026-10-27.

## Does

- იღებს `tk.Tk` ფანჯარას `main.py`-დან.
- ტვირთავს `Config`-სა და `Resources`-ს.
- ქმნის `Canvas`, `Keyboard` და `AppMenu` ობიექტებს.
- აკავშირებს `<Key>` მოვლენას `on_key` მეთოდთან.
- იწყებს, ცვლის და ასრულებს სასწავლო სესიას.
- ამოწმებს დავალების სტრიქონების მინიმალურ რაოდენობას `config.ini`-დან.
- კითხულობს ტექსტურ სავარჯიშოებს `_load_sentences()` მეთოდით.
- მართავს აპლიკაციის დონის kiosk რეჟიმს და ადმინისტრაციულ გასვლას.

## Does not

- არ ითვლის Accuracy-ს, CPM-სა და Success Streak-ს მიმდინარე ძირითად ნაკადში.
- არ იყენებს `TypingEngine`-ს ან `Progress`-ს ამჟამინდელ სესიაში.
- არ არის გრაფიკული კლავიატურის ხატვის კომპონენტი.

## Inputs

- `root: tk.Tk`.
- `config.ini` — ენა, თემა, ფანჯრის რეჟიმი, სავარჯიშოების ფაილი, მინიმალური სტრიქონები.
- `resources/` — თარგმანები, თემები და კლავიატურის მოდელი.
- `data/sentences.txt` (ან `training.sentence_file`-ში მითითებული გზა).
- კლავიშის მოვლენები `tk.Event`.

## Outputs

- აპლიკაციის ეკრანისა და კლავიატურის მდგომარეობა.
- `TypingExercise`-ის დაწყება/შეჩერება.
- მიმდინარე სტრიქონის ინდექსის და სესიის დასრულების მართვა.
- შეტყობინება არასწორი ან არასაკმარისი სავარჯიშო ფაილის შემთხვევაში.

## მეთოდები და შესრულების ნაკადი

| მეთოდი | პასუხისმგებლობა |
|---|---|
| `__init__` | საწყისი კონფიგურაცია, რესურსები, UI, მენიუ და კლავიშების ბმა |
| `start_training` | ფაილის წაკითხვა, მინიმალური მოცულობის შემოწმება, სავარჯიშოს დაწყება |
| `_load_current_line` | შემდეგი `TypingExercise` ობიექტის შექმნა |
| `on_key` | კლავიშის გადაცემა მოქმედ სავარჯიშოზე და სტრიქონებს შორის გადასვლა |
| `finish_training` | UI-ის საწყის მდგომარეობაში დაბრუნება |
| `_secret_finish` | ადმინისტრაციული იძულებითი დასრულება |
| `_enable_kiosk` / `_disable_kiosk` | აპლიკაციის ფანჯრის რეჟიმის მართვა |
| `_load_sentences` | ტექსტური ფაილის კითხვა და ზედა რეგისტრში გადაყვანა |
| `_about` | ინფორმაციული დიალოგის ჩვენება |

### რეალური საკოორდინაციო ნაკადი

```text
main.py
  └── Trainer(root)
       ├── Config, Resources
       ├── Canvas, Keyboard, AppMenu
       └── TypingExercise.on_key(tk.Event)
             └── UI-ის ვიზუალური ბრძანებები
```

**მნიშვნელოვანი შეუსაბამობა:** სასურველი დიზაინით სიმბოლოს შეფასება უნდა იყოს Tkinter-ისგან დამოუკიდებელ `logic/` ფენაში. მიმდინარე `TypingExercise.on_key` თვითონ ადარებს სიმბოლოს მიზანს. `TypingEngine` კი ცალკე არსებობს. ეს საჭიროებს შემდგომ, ტესტებით დაცულ რეფაქტორინგს; **Trainer-ის გადაწერა ახალ ბირთვად დაუშვებელია**.

## Educational rationale

სესიის კოორდინაციისა და გამოთვლების განცალკევება დაგვეხმარება სიზუსტის, პროგრესისა და ადაპტაციის დამოუკიდებელ ტესტირებაში. არსებული სასწავლო ქცევა არ უნდა შეიცვალოს უნებლიე რეფაქტორინგისას.

## Known limitations

- GUI-ის მიმდინარე შესრულება ავტომატურად არ არის შემოწმებული.
- ხარისხის ზღვრები `config.ini`-ში განსაზღვრულია, მაგრამ Trainer მათ არ იყენებს.
- Kiosk რეჟიმი არ არის ოპერაციული სისტემის უსაფრთხოების გარანტია.
- ძველ დოკუმენტში მოცემული `TypingEngine("data/sentences.txt")` მაგალითი მიმდინარე პროგრამის სწორი ინტეგრაცია არ იყო; ის არ გამოიყენოთ წარმოების კოდად.
