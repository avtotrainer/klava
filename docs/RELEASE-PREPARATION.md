# KLAVA — v0.3.2-beta.1 რელიზი

**თარიღი:** 2026-10-30 · **სტატუსი:** გამოშვება ავტორიზებულია მომხმარებლის მიერ; მიმდინარეობს მომზადება.

## ცვლილება

[PR #19](https://github.com/avtotrainer/klava/pull/19) გაერთიანებულია `main`-ში: ერთი მომხმარებლისთვის მხოლოდ ერთი სასწავლო სესია. განმეორებითი გაშვება სრულდება ახალი ფანჯრის გარეშე; პროცესის დახურვა ან ავარია ათავისუფლებს ბლოკირებას. რედაქტორის მალსახმობი ხელმისაწვდომია.

ვერსიები: Python/EXE — `0.3.2-beta.1`; MSI — `0.3.2` (წინაზე მაღალი რიცხვითი ვერსია). MSI-ის UpgradeCode უცვლელია. ძველი `v0.3.1-beta.1` რელიზი და მისი ფაილები არ იცვლება.

## გამოშვების პროცესი

- კანონიკური workflow: `.github/workflows/prepare-beta-release.yml`.
- ჯერ PR-ის შემოწმებები, შემდეგ ავტორიზებული გაერთიანება `main`-ში.
- ამ რელიზის merge commit შეიცავს `[publish v0.3.2-beta.1]` ნიშნულს. workflow ფაილის `main`-ში ცვლილება იწყებს აწყობას; გამოქვეყნებას დამატებით სჭირდება ეს კონკრეტული ნიშნული.
- ხელით გაშვებისას `publish=false` მხოლოდ აწყობას აკეთებს. `publish=true` დასაშვებია `main`-ზე და მხოლოდ `version=v0.3.2-beta.1`-ით.
- ორივე ინსტალატორი აიწყობა იმავე commit-იდან. pytest/Ruff/compileall, ბმულები, რეალური Tk, მეორე EXE-ს უარყოფა, EXE/MSI ინსტალაცია-წაშლა და SHA256 წინ უსწრებს გამოქვეყნებას.
- არსებული tag-ის გადაფარვა იკრძალება. ყველა მომავალი ვერსია საჭიროებს ახალ ცვლილებასა და ავტორიზაციას.

## ფაილები და გამოყენება

რელიზს დაერთვება `KLAVA-Setup-x64.exe`, `KLAVA-x64.msi`, `SHA256SUMS.txt`.
EXE იძლევა მიმდინარე მომხმარებლის ან ყველა მომხმარებლის ინსტალაციის არჩევანს; MSI განკუთვნილია ადმინისტრატორის მიერ კომპიუტერის დონეზე დაყენებისთვის. სხვადასხვა ფორმატის გადასვლისას წინანდელი პაკეტის დეინსტალაციაა საჭირო. მომხმარებლის `%LOCALAPPDATA%/KLAVA` სავარჯიშოები რჩება.

## შემოწმების საზღვრები

PR #19-ის Linux, Windows Installer და MSI CI წარმატებულია. რელიზის საბოლოო აწყობისა და გამოქვეყნების შედეგი შემოწმდება ცალკე. ფიზიკურ სასკოლო კომპიუტერზე მიღება, რეალური შეზღუდული ანგარიშით ინსტალაცია, ძველი MSI-დან განახლება და GPO/Intune ჯერ სრულად გადამოწმებული არ არის. ინსტალატორები ხელმოუწერელია.
