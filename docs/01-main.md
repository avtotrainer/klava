# `main.py` — პროგრამის შესვლის წერტილი

## Does
- იმპორტავს `tkinter`-სა და `Trainer`-ს.
- უშუალოდ გაშვებისას ქმნის `tk.Tk()` ფანჯარას.
- გადასცემს ფანჯარას `Trainer(root)`-ს.
- იწყებს მოვლენების ციკლს `root.mainloop()`.
- შეიცავს ვერსიის სტრიქონს `__version__ = "0.3.1-alfa"`.

## Does not
- არ არჩევს სავარჯიშოებს და არ ამუშავებს კლავიშებს.
- არ ითვლის სიზუსტეს, სიჩქარეს ან პროგრესს.
- არ ქმნის კონკრეტულ UI ელემენტებს `Trainer`-ის ნაცვლად.

## Inputs
- ლოკალური Python/Tkinter გარემო და პროექტის იმპორტირებადი მოდულები.
- `Trainer` დამატებით კითხულობს `config.ini`-სა და რესურსებს; ეს `main.py`-ის პირდაპირი პასუხისმგებლობა არ არის.

## Outputs
- გაშვებული Tkinter აპლიკაცია, რომლის სესიას `Trainer` მართავს.

## რეალური შესრულების ნაკადი

```python
import tkinter as tk
from trainer import Trainer

__version__ = "0.3.1-alfa"

if __name__ == "__main__":
    root = tk.Tk()
    Trainer(root)
    root.mainloop()
```

ეს მაგალითი შეესაბამება მიმდინარე `main.py`-ს. აპლიკაციის ფანჯრის სათაურს ადგენს **Trainer**, რესურსების მიხედვით, და არა `main.py`.

## Educational rationale

შესვლის წერტილის სიმარტივე თავიდან გვარიდებს ლოგიკისა და UI-ის მართვის შემთხვევით შერევას. შესვლის წერტილში ცვლილებები შეიტანე მხოლოდ აპლიკაციის ინიციალიზაციის საჭიროებისას.

## Known limitations

`__version__`-ის სიტყვიერი სუფიქსი `alfa` განსხვავდება CHANGELOG-ში გამოყენებული `alpha`-სგან. ვერსიონირების გასწორება დაგეგმილია ცალკე; ეს დოკუმენტური ცვლილება პროგრამის ვერსიას არ ცვლის.
